# Output
In C#, if you want to print a variable or a value, you can use the following commands:
```csharp
Console.Write(value); // Printing an output without creating a new line. (Similar to using only cout << value; in C++.)
Console.WriteLine(value); // Printing an output and then create a new line. (Similar to using cout << value << endl; in C++.)
```
Example of `Console.Write();`
```csharp
int x = 3;
Console.Write(20);
Console.Write(x);
Console.Write("Hello!");
```

**Output:**
```text
203Hello!
```

Example of `Console.WriteLine();`
```csharp
int x = 3;
Console.WriteLine(20);
Console.WriteLine(x);
Console.WriteLine("Hello!");
```

**Output:**
```text
20
3
Hello!
```

As you can see, both methods are very similar. The main difference is that `Console.Write()` prints the value without moving to a new line, while `Console.WriteLine()` prints the value and then moves the cursor to the next line.

# String Interpolation & Concatenation
Sometimes, we need to combine text with values. For example, suppose we want to print the following sentence in a single command:

`"Hello, my name is [name]!"`  

This is where string interpolation and string concatenation become useful.

**Example of String Interpolation:**
```csharp
string name = "Anfield";
Console.WriteLine($"Hello, my name is {name}!");
```
String Interpolation places a $ before the opening quotation mark and allows variables or expressions to be inserted directly inside {}.

**Output:**
```text
Hello, my name is Anfield!
```

**Example of String Concatenation:**
```csharp
Console.WriteLine("Hello, my name is " + name + "!");
//String Concatenation (Joining Strings in output, similar to using cout << "Hello, my name is " << name << "!";)
```

**Output:**
```text
Hello, my name is Anfield!
```

String Concatenation combines multiple strings and values using the + operator. This is similar to:
```cpp
cout << "Hello, my name is " << name << "!";
```
