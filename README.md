# My C# Learning Journey
A collection of my reflections, learning notes, and progress in C#, as a former competitive programmer transitioning from C++ to C#.

# 🐰 Who am I?  

Greetings, everyone.  

I'm Anfield. During my high school years, I was a competitive programmer and spent most of my time coding exclusively in C++.  
Despite that, I've always had the ambition of becoming a Software Engineer at Microsoft, which inspired me to begin my C# learning journey a few months ago.
At that time, I spent a few weeks exploring the language and learning its fundamentals before taking a long break due to university commitments and tutoring responsibilities.  

Recently, I've returned to studying C# and have been reviewing it consistently for the past week.  
To stay motivated and document my progress, I decided to create this repository as a place to track my learning journey and build a portfolio of my work.  

If you're viewing this repository years from now, I hope you'll be able to see how much I've grown. There is still so much for me to learn and explore in the world of software development.

I also hope that some part of this repository can be helpful to others who are learning alongside me.  
May freedom be with you.

# 🎯 Objectives  

This repository documents my journey of learning C#, understanding its ecosystem, and developing better software engineering practices.
Rather than simply collecting syntax and examples, I aim to understand how things work, why certain approaches are preferred, and how to apply what I learn in practice.

# 📚 Contents  

- Learning Notes — Concepts, explanations, and observations from my C# studies.
- C++ to C# — Comparisons, differences, and lessons learned while transitioning between languages.
- Experiments — Small programs and exercises exploring language features and behavior.
- Projects — Practical applications of the concepts I've learned.
- Reflections — Personal insights, mistakes, and lessons from my learning journey.

# 🧭 Learning Progress  
This repository will evolve alongside my studies. Topics and projects will be added as I explore them, experiment with new ideas, and deepen my understanding of C#.

# 💡 Learning Philosophy  
I prefer understanding code before writing, as my goal isn't merely to learn another programming language, but to become a better developer by understanding the tools I use, making thoughtful design decisions, and continuously learning from experience.
